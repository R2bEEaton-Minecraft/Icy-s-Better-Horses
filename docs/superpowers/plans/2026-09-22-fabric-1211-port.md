# Fabric 1.21.1 2.0 Port Plan

## Task 1: Establish the reproducible Fabric 1.21.1 baseline

Update Gradle/Loom/Java/dependency coordinates to the supplied pack. Resolve
all dependencies from public repositories and compile a minimal Fabric 1.21.1
source slice. Verify `compileJava` and `test`.

## Task 2: Port common 1.21.1 gameplay

Use the NeoForge branch to translate entity, item, feature, command, network,
and common mixin code to 1.21.1 APIs. Retain Fabric registries, events, and
entrypoints. Add focused regression tests for pure logic. Verify a server-side
development launch.

## Task 3: Preserve 1.1.6 data

Port the NeoForge branch's `CompoundTag` persistence paths, including legacy
breed and position fallbacks. Add fixture-based tests for 1.1.6 `BH_*` data.
Verify that loading and saving a fixture preserves the supported fields.

## Task 4: Port client systems

Replace 26.2 GUI/render extraction and render-state APIs with their 1.21.1
counterparts. Convert GeckoLib 5 calls to GeckoLib 4. Port client mixins and
entity renderers from the NeoForge reference while retaining Fabric client
registration. Verify a development client reaches the title screen and renders
every custom horse, tack, stabilizer, and cart.

## Task 5: Complete pack compatibility verification

Install the built jar in copies of the supplied server/client folders, remove
the old 1.1.6 jar, and launch both sides. Inspect logs for duplicate registries,
mixin failures, datapack errors, and Cobblemon/Alex's Mobs/YUNG's conflicts.
Verify all spawn tags resolve against the pack's Terralith and BYG jars.
